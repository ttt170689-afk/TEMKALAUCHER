# Перенос Dev-управления

1. Закрой старый Publisher и установи **TemkaPublisher-Setup-1.1.2.exe**. Сохранённый вход Beta Test совместим; новая Dev-регистрация не нужна.
2. Для приглашений: **Beta Test → Dev · ПК → Проверить Dev-доступ**. Выдача и отзыв требуют Dev-owner на сервере, не просто nickname или игрового creator-флага.
3. Чтобы убрать кнопки из уже установленного лаунчера, опубликуй **TemkaLauncher-1.9.7-sources.zip** обычным ZIP-потоком, версия **1.9.7**. Старые теги не перезаписывать.
4. Дождись Windows и Linux gates. Без обоих успешных jobs релиз не публикуется.
5. Брат использует обычный лаунчер, свой основной подтверждённый аккаунт → Dev → приглашение. Один tester-слот.

Роли/SQL/SMTP/Gateway/аккаунты и ранее активированный доступ не сбрасываются. Если скриншот с НЕИСПОЛЬЗОВАННЫМ приглашением передавался посторонним, владелец может создать новый — он отменит предыдущий. Ранее скачанные файлы отзыв не удаляет.
