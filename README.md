# TemkaLauncher 1.5.8 · Альфа

## Исправление HTTP 403 при проверке обновлений

В 1.5.7 проверка начиналась с GitHub REST API. Этот API может вернуть 403/429 из-за лимитов или запретов доступа. По одному коду 403 конкретную причину установить нельзя.

Теперь updater **вообще не обращается к api.github.com**:

1. Читает маленький `latest.yml` напрямую из `https://github.com/ttt170689-afk/TEMKALAUCHER/releases/latest/download/` (для Linux — `latest-linux.yml`).
2. Проверяет обычную SemVer-версию, допустимые имена файлов своей платформы, целый положительный размер, формат SHA-512, отсутствие дубликатов и внешних URL.
3. Читает манифест из конкретного тега `v<version>` и сравнивает список файлов, размеры и SHA-512.
4. Делает **HEAD**, не GET, для выбранного установщика: проверяет существование и Content-Length, если сервер прислал его. Тело EXE/AppImage при проверке не скачивается.
5. Передаёт движку URL конкретного релиза. Согласует ответ движка с проверенными метаданными. Само скачивание/проверка содержимого пакета остаются у electron-updater.

Токены, отключение TLS и обход сетевых запретов не используются. Если недоступен сам файловый хостинг GitHub, ошибка остаётся видимой — это не «обновлений нет». Разделение по каналам не менялось: «Альфа» — обозначение стадии продукта; GitHub-релиз обычный, не prerelease.

## Выпустить через Publisher

1. Закрой старый Publisher. Установи **TemkaPublisher-Setup-1.0.7.exe** либо распакуй portable и запусти EXE из новой папки. В заголовке должно быть **1.0.7**.
2. Выбери `TemkaLauncher-1.5.8-sources.zip` без распаковки.
3. Репозиторий `ttt170689-afk/TEMKALAUCHER`. Номер **1.5.8**, если свободен, иначе следующий предложенный.
4. Дождись успешной сборки Windows и Linux и сообщения «ГОТОВО». Не перезаписывай существующие теги и релизы.

Старый Publisher 1.0.6 вставит старый native-код с API. Защита `src/lib/nativeContract.ts` теперь требует `electron/release-feed-contract.json`: при старом шаблоне сборка остановится, а не выпустит старый механизм заново.

## Как получить исправление на своём ПК

Если установленная 1.5.7 из-за 403 не сможет обновиться сама, **после успешной публикации** скачай Setup новой версии со страницы:
https://github.com/ttt170689-afk/TEMKALAUCHER/releases/latest

Проверь тег 1.5.8, полностью закрой старый лаунчер (в том числе трей) и установи поверх в ту же папку. Не удаляй AppData и профили. Запусти новый ярлык. В результате успешной проверки источник должен быть **«GitHub Releases · напрямую, без API»**.

Новая логика заработает только после установки новой программы; файлы на GitHub сами по себе код старой установленной копии не меняют.

## Остальное сохранено

XP не начисляется; вишлист без email локальный; системный выбор папки, профиль/аватар, ники до 25 символов, новости и подпись разработчика сохранены. Исторический XP не стирается. Игры пока не устанавливаются, backend друзей не развёрнут. Сайт и его запланированная страница Fantazia RP в этом исправлении не менялись.

## Проверки и ограничения

Node 22.12+: `npm ci`, `npm test`, `npm run build`. UI: `npm run test:smoke`, `node scripts/smoke-updates.cjs`, `node scripts/smoke-news.cjs`, `node scripts/smoke-alpha.cjs`. В Linux UI запускается через `xvfb-run -a`.

`node scripts/check-release-live.cjs` проверяет реальные метаданные без загрузки установщика; используется тестовый currentVersion и Windows-platform для NSIS-проверки под Linux. Это не полная установка Windows. Большой EXE в рабочую папку не скачивался/не собирался. 1.5.8 не опубликована из этой сессии.
