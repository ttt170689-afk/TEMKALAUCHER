# TemkaLauncher 1.6.3 · Альфа

## Подключён проект друзей и бета-доступа

Публичная конфигурация проекта включена в `src/config/online.public.json`. В ней только Project URL и publishable key — не пароль и не администраторский ключ. Файл сохраняется при импорте исходников в Publisher. Для этого проекта добавлять Actions Variables не нужно. Если они уже заданы для другого проекта, удали ОБЕ старые переменные TEMKA_SUPABASE_URL / TEMKA_SUPABASE_ANON_KEY или замени ОБЕ на нужный проект: явные переменные сборки имеют приоритет.

Установленный раньше лаунчер сам не получает новые настройки — нужен выпуск с новым свободным номером через Publisher. Эта версия включает настройки, но **реальный вход по почте, отправка писем друзьям и роль владельца ещё требуют настройки/проверки**. Подключение подтверждено только чтением Auth settings: Email включён, регистрации разрешены, подтверждение email требуется; анонимное чтение таблиц запрещено. Аккаунты/письма проверкой не создавались.

После настройки почты: Профиль → онлайн-профиль → Получить код → Подтвердить почту → сохранить онлайн-ник. Это отдельно от локального профиля; локальные пароли на сервер не загружаются. Далее друзья по полному онлайн-нику; бета-код через Библиотека → ⋯ → Свойства → Бета-тест. Роль creator_admin назначается владельцем в SQL Editor только по UUID своего подтверждённого Auth-пользователя, не по нику.

Отключение публичного чтения таблиц нужно сохранить: не выдавай anon SELECT по подсказке ошибки API. Для бета-кодов нет прямого доступа к таблицам. Бета-доступ пока не раздаёт исполняемые файлы и не закрывает публичную браузерную игру.

## Исправлена повторная ошибка native contract

Publisher 1.0.6 заменял папку `electron/` шаблоном с protocol 2/API, а интерфейс ожидал protocol 3. В итоге отсутствовал `electron/release-feed-contract.json`, и сборка останавливалась.

В этом ZIP нужный desktop-код дополнительно хранится в `native-bundle/` — этой папки старый Publisher не касается. Основной `vite.config.js` восстанавливает известный набор native-файлов, updater UI и тестов до формирования приложения, затем повторяет TypeScript и runtime-тесты. Если комплект отсутствует, изменён или повреждён, сборка не продолжается. SHA-256 нормализует LF/CRLF для Windows checkout; это контроль целостности комплекта, не цифровая подпись автора.

**Проверка не отключена и пустой JSON не подставляется.** Реально восстанавливается прямой механизм GitHub Releases без REST API. Первичный TypeScript читает contract из неизменяемой старым Publisher папки комплекта.

Vite штатно выбирает `vite.config.js` раньше `vite.config.ts`. Файл `.ts` оставлен для совместимости со старым шаблоном и его tsconfig. Не удаляйте `.js` и не запускайте сборку с принудительным `--config vite.config.ts`.

## Выпустить

1. Используйте уже установленный **Publisher 1.0.9, вкладку «Лаунчер · Windows / Linux»**.
2. Выберите целиком `TemkaLauncher-1.6.3-sources.zip` без распаковки.
3. Номер **1.6.3**, если свободен; иначе следующий предложенный. Репозиторий `ttt170689-afk/TEMKALAUCHER`.
4. Дождитесь «ГОТОВО». Старые неудачные 1.5.6/1.5.8 не перезаписывайте. Re-run прежней сборки не заменяет её исходники.

Строки `[Temka runtime]` в логе `npm run build` подтверждают восстановление и повторные проверки. В новых файлах обновления должен использоваться источник **«GitHub Releases · напрямую, без API»**.

Если установленная копия из-за 403 не обновится сама, после публикации скачайте новый Setup со страницы Releases, полностью закройте лаунчер, включая трей, и установите поверх в ту же папку. Не удаляйте AppData/профили.

## Разработка

Node 22.12+: `npm ci`, `npm test`, `npm run build`. Правильная production-команда — `npm run build`, как в workflow Publisher. Она выполняет первичную типизацию, восстановление, повторную типизацию и runtime-тесты, затем Vite.

Для изменений в desktop-коде/восстанавливаемых файлах обновляйте также `native-bundle` и его `manifest.json`; иначе при следующей сборке вернётся содержимое комплекта. Скрипт для обновления: `node build-tools/refresh-bundle.mjs` из корня проекта. Менять их следует согласованно, с повторными тестами.

XP отключён, локальный вишлист без почты, системный выбор папки, профиль/аватары/новости сохранены. Backend друзей/игры не развёрнуты. Сайт в этом исправлении не изменён. Выпуск 1.6.3 из чата не опубликован; большой Windows EXE не скачивался и не собирался.
