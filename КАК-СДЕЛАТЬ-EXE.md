# 🖥 Как собрать TemkaLauncher в EXE

Сборка делается **на твоём компьютере с Windows** (в этой веб-среде exe собрать нельзя).

## 🚀 Способ 0 — Electron (рекомендую: трей + надёжное закрытие)

В Electron лаунчер ведёт себя как настоящая программа:
**крестик сворачивает в трей** (иконка у часов, правый клик → «Открыть» / «Выход»),
лаунчер работает в фоне и всегда закрывается через меню трея или кнопку в настройках.

```bash
npm install
npm install --save-dev electron electron-builder   ← один раз, качает ~110 МБ
npm run build
npm run app      ← проверить окно
npm run dist     ← собрать EXE в папку release/
```

> Да, первая загрузка Electron долгая (~110 МБ, один раз). Зато потом —
> полноценный установщик `TemkaLauncher-Setup.exe` и portable-версия,
> нативный трей и никаких «не могу закрыть».
> Если интернет совсем медленный — качай через торрент-зеркало или у друга,
> папка кэша: `%LOCALAPPDATA%\electron\Cache`.

## Запасной способ — Neutralino (exe ~2 МБ, без трей-меню)

Если Electron так и не докачался — запусти **`BUILD-EXE.bat`**:
соберёт лаунчер через Neutralino (системный WebView2). Там крестик сворачивает
в трей через JS-API, но нативный Electron-трей надёжнее.

## Способ 1 — Electron (опционально, если Neutralino не подошёл)

> ⚠️ Качает ~110 МБ и часто тормозит на слабом интернете. Если Electron у тебя не пошёл —
> используй **BUILD-EXE.bat** выше или PWA ниже.
>
> Всё уже настроено: `"main"` и скрипты прописаны в `package.json`, ничего править не нужно.

### 1. Скачай проект и открой терминал в его папке

### 2. Установи зависимости
```bash
npm install
npm install --save-dev electron electron-builder
```

### 3. Собери лаунчер (веб-часть)
```bash
npm run build
```
Появится папка `dist/` с одним файлом `index.html` — Electron грузит именно его.

### 4. Проверь как приложение (без сборки exe)
```bash
npm run app
```
Откроется настоящее окно TemkaLauncher (тёмное, 1380×880, F11 — весь экран).

### 5. Собери EXE
```bash
npm run dist
```
Через пару минут в папке **`release/`** появятся:
- **`TemkaLauncher-Setup.exe`** — полноценный установщик (выбор папки, ярлыки на рабочем столе и в меню Пуск)
- **`TemkaLauncher-Portable.exe`** — портативная версия: запустил — работает, без установки

Готово! 🎉

### Все команды одной шпаргалкой
| команда | что делает |
|---|---|
| `npm run build` | собирает веб-часть в `dist/` |
| `npm run app` | запускает лаунчер как десктоп-приложение |
| `npm run dist` | собирает **EXE** (установщик + portable) |
| `npm run updater` | собирает **EXE-апдейтер** |
| `npm run pack-update` | пакует обновление (zip + манифест) |

## Способ 2 — PWA: приложение БЕЗ сборки вообще (работает прямо сейчас)

Лаунчер уже умеет ставиться как настоящее приложение из браузера:
своё окно без адресной строки, иконка в панели задач, **офлайн-режим**.

1. Открой лаунчер в **Chrome / Edge / Яндекс.Браузере**
2. В адресной строке появится значок установки (или меню → «Установить TemkaLauncher…»)
3. Подтверди — готово: TemkaLauncher откроется в отдельном окне как обычная программа

Кнопка **«Установить как приложение»** также есть в Настройки → «О лаунчере».
Всё уже настроено: `public/manifest.webmanifest`, `public/sw.js` (кэш → офлайн), иконка.
Никакого Electron, никаких загрузок на 100 МБ.

> Если Electron у тебя не пошёл — начни отсюда. Это самый быстрый путь.

## Способ 3 — Neutralino: настоящий EXE ~2 МБ (без Electron и Rust)

[Neutralino](https://neutralino.org) пакует лаунчер в крошечный exe и использует
системный WebView2 (уже стоит в Windows 10/11). Конфиг `neutralino.config.json` уже в проекте.

```bash
npm run build
npm install -g @neutralinojs/neu
neu update          # скачает нейтральный бинарник (~2 МБ, не 110)
neu build
```
Готовый exe лежит в `dist-neutralino/TemkaLauncher-win_x64/` — папку можно просто скопировать
куда угодно и запускать `TemkaLauncher.exe`.

> Если `neu update` попросит другие версии бинарника — поправь `binaryVersion`/`clientVersion`
> в `neutralino.config.json` по таблице на neutralino.org/docs/cli/configuration.

## Способ 4 — Pake (быстро, exe ~5 МБ)

[Pake](https://github.com/tw93/Pake) пакует сайт в крошечный exe.

```bash
npm run build
npx serve dist        # поднимет локальный сервер, например http://localhost:3000
```
В **другом** терминале:
```bash
npm install -g pake-cli
pake http://localhost:3000 --name TemkaLauncher --width 1380 --height 880 --fullscreen --transparent
```
EXE появится в папке проекта. Сервер после этого можно выключить — exe работает сам.

## 🌐 Автообновления через GitHub (без zip-ов вручную)

Лаунчер сам ходит в твой GitHub-репозиторий, сравнивает версии,
скачивает пакет и ставит его — игроку достаточно нажать «Установить» (или вообще ничего:
плашка появится сама при запуске).

### Один раз — настройка

1. Создай **пустой публичный** репозиторий на github.com (New repository → имя, например `temkalaucher`).
2. В папке проекта выполни:
   ```bash
   git init
   git add .
   git commit -m "TemkaLauncher v1.2.0"
   git branch -M main
   git remote add origin https://github.com/ТВОЙ_НИК/temkalaucher.git
   git push -u origin main
   ```
   (GitHub попросит войти — один раз.)
3. Открой файл **`updater-source.txt`** (в корне проекта, а у игроков — рядом с exe)
   и впиши туда одну строку со своей ссылкой:
   ```
   https://raw.githubusercontent.com/ТВОЙ_НИК/temkalaucher/main/updates/manifest.json
   ```
   Пересобирать exe после этого **не нужно** — лаунчер читает файл при каждой проверке.
4. Собери exe (`npm run dist` или `BUILD-EXE-ELECTRON.bat`) и раздавай — он уже смотрит на GitHub.

### Каждый раз, когда вышла новая версия

1. Правь код лаунчера как обычно. По желанию открой `updates/manifest.json`
   и обнови список `notes` («что нового» — его увидят игроки в плашке).
2. Запусти **`PUBLISH-UPDATE.bat 1.4.0`** (номер версии — свой).
   Батник сам: соберёт лаунчер → упакует → закоммитит `updates/` → запушит на GitHub.
3. Всё. Игроки даже перезапускать ничего не должны сразу: их лаунчеры
   **каждые 5 минут** сами проверяют GitHub, сами скачивают и меняют файлы,
   а игроку остаётся нажать «Перезапустить» (или вообще ничего — до следующего запуска).

> Если интернет у игрока отвалился — лаунчер молча возьмёт локальную папку `updates/`
> (в сборку она тоже кладётся через `extraResources`).
> Интервал и автоустановка выключаются в Настройки → Уведомления.

## ⚡ Самообновление лаунчера (встроено)

Лаунчер **сам** проверяет обновления при запуске и по кнопке в настройках:
внизу экрана появляется живая плашка «Доступно обновление v1.3.0» со списком изменений.
Лаунчер **ждёт клика** — по кнопке «Установить» он скачивает пакет с прогресс-баром,
заменяет свои файлы и предлагает «Перезапустить».

- `dist/` и `version.json` упакованы **вне asar** (`asarUnpack`), поэтому лаунчер может перезаписать себя на лету.
- Если пакет обновления содержит `TemkaLauncher-Updater.exe` — лаунчер заменит и его. Так апдейтер обновляется сам через лаунчер.
- Ссылку на удалённый манифест (GitHub Releases и т.п.) можно вписать в `electron/main.cjs` → `MANIFEST_URL`.

## 🔄 Программа обновления (TemkaLauncher-Updater.exe)

В проекте есть отдельный апдейтер (`updater/`) — красивое окно в стиле лаунчера, которое:
проверяет версию по манифесту → показывает «что нового» → скачивает пакет с прогресс-баром →
распаковывает и заменяет файлы → перезапускает лаунчер.

### Собрать апдейтер
```bash
npm run updater
```
Появится `release-updater/TemkaLauncher-Updater.exe` (portable — просто положить рядом с лаунчером).

### Проверить прямо сейчас (без сборки exe)
```bash
npx electron updater/main.cjs --target=.
```
Он увидит, что установлена v1.2.0, а в `updates/manifest.json` есть v1.3.0 — и предложит обновиться
(тестовый пакет `updates/TemkaLauncher-dist-1.3.0.zip` уже в проекте).

### Как выкатывать обновления игрокам
1. Соберите новую версию лаунчера: `npm run build`
2. Запакуйте её: `npm run pack-update -- 1.3.1` (создаст zip и обновит манифест)
3. Загрузите папку `updates/` (manifest.json + zip) на любой хостинг — GitHub Releases, S3, свой сервер
4. Впишите ссылку на манифест в начало `updater/main.cjs`:
   ```js
   const MANIFEST_URL = "https://raw.githubusercontent.com/USER/REPO/main/updates/manifest.json";
   ```
   и пересоберите апдейтер один раз — дальше всё автоматически.

Кнопка **«Проверить обновления лаунчера»** в настройках сама запускает апдейтер,
если `TemkaLauncher-Updater.exe` лежит рядом с лаунчером.

## Примечания

- **Данные хранятся локально**: аккаунты, XP, уровень, лист ожидания и настройки — в localStorage приложения (у Electron это папка `%APPDATA%/TemkaLauncher`).
- **Веб-демо Fantazia RP** (ссылка «В браузере») автоматически открывается в системном браузере.
- Если хочешь совсем «как из магазина» — способ 1 даёт установщик с иконкой Temka и ярлыками.
- Антивирусы иногда ругаются на неподписанные exe — это нормально для собственной сборки; для раздачи друзьям подойдёт portable-версия.
