# Опубликовать TemkaLauncher 1.9.8 — отдельный Dev-режим

1. Открыть имеющийся **TemkaPublisher 1.1.2**. Новый Publisher для этого обновления не требуется.
2. В обычном разделе публикации лаунчера выбрать **TemkaLauncher-1.9.8-sources.zip** (не вкладку сайта и не Beta Test).
3. Указать новую версию **1.9.8** и запустить штатную публикацию. На момент read-only проверки тег v1.9.7 существовал, v1.9.8 отсутствовал. Если номер уже занят, выбрать следующий свободный; опубликованные теги не перезаписывать.
4. Дождаться успешных Windows и Linux проверок. Не пропускать smoke/gates. Сборка и выпуск выполняются штатным процессом Publisher/GitHub; здесь релиз не запускался.
5. После получения обновления: обычный лаунчер → **Dev → Войти в Dev**. Владелец использует уже существующий доступ. Брат один раз активирует приглашение от владельца; повторный вход без повторного кода.
6. Внутри отдельный Dev-интерфейс. Возврат — верхняя кнопка или Escape. MAIN-вход остаётся.

Существующие Dev-роли/шлюз/SQL/SMTP не сбрасываются. Управление приглашениями только **Publisher → Beta Test → Dev · ПК**. Закрытое окружение предназначено для функций лаунчера, не игр. Отдельные ранние функции пока не разработаны; файл обновления их не имитирует и не публикует закрытый бинарник автоматически.

Публичный updater не меняет канал. Каталог внутри Dev — вспомогательная отдельная загрузка; файлы проверяются и автоматически не запускаются. Большого EXE в комплекте нет; это исходный ZIP для программы публикации.
