# Проверки TemkaLauncher1.8.0 · 13.10.2026

## Объём и решения владельца

Только ПК Windows/Linux; мобильный0.3.0 не менялся. Профили доступны всем вошедшим игрокам с подтверждённой почтой; уровень отдельный у каждой игры, без нового XP лаунчера. Бета остаётся реестром допуска до подключения самой игры. Discord не создан из чата — подготовлен план ручного создания/прав. Роль creator_admin и ник владельца уже подтверждены пользователем; повторная выдача не нужна.

## Чего не делали

Windows OS/runner/installer/GitHub Release не запускались в чате. Linux + CRLF не заменяет Windows E2E. Большой Windows установщик не скачивался/не собирался. Новая миграция в реальном проекте ещё должна быть выполнена владельцем. Никаких OTP/рабочих токенов/производственных SQL операций этим тестом не отправлено.

Часы/уровни/награды в native SQL/UI fixtures — явно синтетические данные в изолированных тестах, не пользовательская статистика и не seed для production. Сборщик игровых сессий/защищённая браузерная бета/связь Discord ролей не реализованы. Поля базы и отображение готовы; нужны интеграция самой игры и серверная проверка игровых событий. До этого production карточки показывают «Нет данных».

Фото в публичном бакете остаётся доступным по прямой ссылке; новый UI сообщает об этом до выбора. Авторизация карточки не делает storage private. Старые локальные фото не мигрируются без действия пользователя. Для старого фото после обновления и входа нужно выбрать файл заново.

Исходники тестов находятся в tests/, scripts/smoke-electron.cjs, scripts/smoke-major.cjs, backend/test-*.py. SQL tests запускаются только против пустой disposable DB, не Supabase. CI не отключён, новых skips/continue-on-error нет.
