# TemkaLauncher1.8.0 — что сделать владельцу

Это обновление только ПК (Windows/Linux). Mobile0.3.0 оставлен прежним по твоему выбору. SMTP, пользователи и creator_admin уже настроены — не пересоздавать их.

## 1. Один раз дополнить сервер

Supabase → SQL Editor → New query. Вставь **backend/player-profiles.sql** целиком и нажми Run. Отдельная копия в комплекте называется **Temka-Player-Profiles-1.8.0.sql**.

Ожидаемый результат: **TEMKA_PLAYER_PROFILES_READY**.

Скрипт добавляет поля карточки, ограниченный поиск по части ника, чтение профиля и таблицу игровой статистики. Не удаляет аккаунты, роли, друзей, аватары или бета-доступы. Его можно повторить. Исходный supabase.sql заново НЕ выполнять. Старые клиенты сохраняют точный поиск и прежние RPC.

Этот SQL из чата в твоей базе НЕ запускался. Без него новая библиотека/копирование работают, но новые профили и частичный поиск покажут, что серверное обновление ещё не подключено. Не заменять ошибку пустым «успешным» профилем.

## 2. Выпустить клиент

В существующем Publisher выбери **TemkaLauncher-1.8.0-sources.zip**, свободную версию **1.8.0**, обычную вкладку лаунчера. Не перезаписывать старые опубликованные теги. Publisher обновлять не нужно.

Дождись успешного Actions и обнови установленный клиент. Здесь не собирался большой Windows EXE и не запускалась публикация в GitHub.

## 3. Проверить с братом

1. Оба входят в подтверждённый онлайн-профиль и сохраняют юзернейм.
2. Профиль → «Как меня видят другие игроки»: сохранить имя/описание, открыть свою карточку.
3. В «Аватар игрока» выбрать фото. При онлайн-входе и выбранном юзернейме оно отправляется сразу; отдельной «Публикации» больше нет. Старые локальные фотографии автоматически не загружаются. Если фото было выбрано раньше — выбрать файл ещё раз после входа.
4. «Друзья → Добавить друга»: ввести хотя бы2 символа ника, нажать «Найти друга». Нажать на аватарку/ник в результате, проверить карточку и отправить заявку. Второй принимает через колокольчик. Профиль можно открыть также из списка друзей/уведомления.
5. Проверить копирование @юзернейма вставкой Ctrl+V в Блокнот.
6. Библиотека: выбрать Fantazia/TemkaWorld, проверить обзор/разработку/дополнения/мой прогресс, поиск и вишлист. «⋯ → Свойства» и бета сохранены.

## Что значит «Нет данных»

Это не поломка счётчика. Сами игры пока не подключены к передаче уровня, времени и достижений. Лаунчер не выдумывает их и не считает часы от открытого окна или перехода по ссылке.

Таблица `public.player_game_stats` готова для доверенного игрового backend: ключ `(user_id,game_id)`, поля `level`, `play_seconds`, `last_played_at`, `achievements` (id/title/earned_at), `achievements_total`, `updated_at`. `game_id`: fantazia / temkaworld. Нет строки или null-поле → «Нет данных». Достижения не подключены, пока отсутствует total.

Обычный клиент НЕ может записать/прочитать сырую таблицу или прибавить себе уровень. Читать разрешённую карточку можно только через проверяемый RPC. Запись — доверенным игровым сервером (service_role только в секретах серверного окружения), который проверяет игровую сессию и реальное время. Ни секретный ключ, ни универсальная команда «прибавить часы» не должны попадать в браузерную игру/лаунчер.

Для автоматической статистики нужны исходники/интеграция самой игры. Схема хранения и отображение уже есть; сборщик игровых сессий в этот выпуск не входит.

## Приватность и аватар

- Профили смотрят вошедшие игроки с подтверждённой почтой. Почта, локальный пароль, местные пути и токены в карточку не попадают.
- Публичное имя/описание сохраняются только по кнопке. Локальное имя остаётся отдельным.
- При новом выборе фото в онлайн-профиле интерфейс предупреждает о публикации. Бакет avatars остаётся публичным: сам файл доступен по прямой ссылке и может кэшироваться. Авторизация карточки не делает эту ссылку приватной. Не загружать чувствительные фото.
- Удаление фото/выбор встроенного аватара убирает опубликованный файл через прежний API и сохраняет встроенный стиль. При сетевом отказе показывается ошибка. Цвет рамки собственного фото локальный; сама фотография общая.
- Настраиваемая приватность «только друзья» сейчас не добавлялась: выбран вариант «все вошедшие игроки».
