# Проверить с братом · ПК 1.9.0 / Android 0.4.0

1. Владелец выполняет backend/online-1.9.0.sql один раз на существующем сервере. Затем ПК обновляется через Publisher, на Android устанавливается новый APK.
2. Каждый подтверждает свою почту в онлайн-профиле. Один и тот же человек использует ту же почту на обоих устройствах; брат — отдельный аккаунт. Локальное имя не выдаёт серверных прав.
3. Найти друг друга по части @юзернейма, отправить заявку, принять в уведомлениях. Открыть карточку друга, проверить фото/имя/роль без раскрытия email.
4. Нажать «Написать», отправить текст ПК → Android, затем ответ. Закрыть диалог, дождаться непрочитанного, открыть; перезапуск не должен потерять серверную историю.
5. Временно отключить сеть и попробовать отправить текст. В открытом диалоге текст при ошибке не очищается; после восстановления повтор не должен создать дубль. Не пересылать реальные пароли/OTP — чат не E2E.
6. Удаление из друзей сохраняет историю, но запрещает новые сообщения. Выход из онлайн-аккаунта сразу закрывает ЛС и убирает чужие данные.
7. На Android проверить все шесть разделов, редактирование имени до 25 символов, фото, копирование @юзернейма, вишлист без почты и «⋯ → Свойства → Бета-тест». При неудаче фото/прав доступа не должно быть ложного успеха.
8. «Скоро» у обеих игр остаётся неактивным. До подключения готовой игры игровые сессии не появляются; нет выдуманных уровней/часов. Проверка настоящего live-статуса требует позже подключённого отслеживаемого билда.

Нет звонков, файлов, push при закрытом приложении, магазинов и мобильного автообновления. APK тестовый, телефон здесь не запускался; при проблеме нужна модель телефона/Android и точный текст ошибки, не пароль или код входа.
