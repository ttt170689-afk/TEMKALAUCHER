# Вход в TemkaLauncher · ПК 1.9.2 / Android 0.4.2

## Уже есть общий аккаунт
1. На первом экране оставь **«Войти в аккаунт»**.
2. Укажи ту же почту, которую раньше подтверждал в онлайн-профиле на ПК.
3. Нажми **«Получить код»**, затем введи цифры из письма и нажми **«Подтвердить и войти»**.
4. Лаунчер откроется с этим общим аккаунтом. Друзья, переписка, серверный @юзернейм и права берутся с прежнего сервера.

Не нужно сначала регистрировать отдельный локальный аккаунт телефона. Вход не создаёт новую общую учётную запись (`create_user=false`). Пароль старого локального профиля и пароль почты здесь не нужны.

## Новый пользователь / раньше был только локальный профиль
Выбери **«Создать аккаунт»** → почта → код из письма → новый @юзернейм (3–25 символов). Сервер проверит занятость. Если эта почта уже имеет общий профиль, откроется он: существующий юзернейм не меняется. Локальная регистрация в старой версии, без подтверждения почты в онлайн-профиле, сама по себе НЕ создавала общий аккаунт.

## Старые данные устройства
Кнопка **«Локальный режим»** открывает прежнюю регистрацию/вход с локальным паролем. Старые записи, фото и настройки не удаляются. Неподтверждённое совпадение имени/почты не объединяет аккаунты: для переиспользования записи нужна уже сохранённая связь с тем же серверным ID. Локальные фото/имена/настройки не обещаны как автоматически синхронизируемые данные; онлайн-профиль отображается отдельно.

## Ошибки и выход
- Не приходит письмо: проверь адрес, «Спам»; повторная отправка доступна через 60 секунд. Отмена и переход в локальный режим не открывают аккаунт по запоздавшему ответу.
- Неверный/старый код: используй последнее письмо или запроси новый код.
- «Общий аккаунт не найден»: возможно, раньше был только локальный профиль. Выбери отдельную регистрацию общего аккаунта.
- Сбой связи/сохранения не означает, что ник свободен или аккаунт отсутствует. Освободи место/восстанови связь и повтори.
- **«Выйти из аккаунта»** в Профиле закрывает локальную сессию и удаляет сохранённые онлайн-токены этого профиля на устройстве. Остальные устройства не выходят. Данные/друзья/переписка на сервере не удаляются.
- Для другого общего аккаунта сначала выйди из лаунчера, затем введи его почту на первом экране.

## Установка владельцем
- Телефон: установить `TemkaLauncher-Mobile-0.4.2.apk` поверх 0.4.1/0.4.0. Тот же appId и сохранённая тестовая подпись; удалять старое приложение не нужно.
- ПК: `TemkaLauncher-1.9.2-sources.zip` → существующий **TemkaPublisher 1.1.0**, вкладка лаунчера → новая публикация 1.9.2. Не переиздавай существующий тег.
- Сайт: `Temka-Studio-Android.zip` → вкладка сайта того же Publisher → публикация файлов в `ttt170689-afk/temka_play_site`. APK 0.4.2 включён в ZIP. Publisher не ждёт и не проверяет Vercel.
- Новый Publisher, новый сервер, SQL-миграция и перенастройка Gmail SMTP для этого исправления не нужны. GitHub/Vercel/production Auth из чата не изменены.

Проверки Auth выполнены с подставным сервером, реальные письма не отправлялись. Android APK собран и проверен по подписи/содержимому; физический телефон/Windows не запускались. iOS — исходный Xcode-проект, не подписанный IPA. Игры всё ещё «Скоро»; управление бета-тестом только в TemkaPublisher.
