# Beta Test в Publisher + APK на сайте

## По порядку
1. Закрой старый Publisher. Установи **TemkaPublisher-Setup-1.1.0.exe**, открой новый ярлык: заголовок должен показывать **1.1.0**.
2. Вкладка **Beta Test** → почта твоего существующего онлайн-аккаунта создателя → код из письма → войти. Выбери игру, режим одобрения, число мест и часы → «Создать ключ» → сразу скопируй. Подробности и отзыв доступа — BETA-TEST.md в исходниках Publisher.
3. Чтобы убрать управление у себя в лаунчере, опубликуй **TemkaLauncher-1.9.2-sources.zip** во вкладке лаунчера, версия **1.9.2**. Старые опубликованные теги не перезаписывать.
4. На телефоне установи **TemkaLauncher-Mobile-0.4.2.apk** поверх прежней тестовой версии с той же подписью. Android8+, актуальный System WebView. Если подпись не совпадает, не удаляй старое приложение без необходимости: удаление стирает локальные данные. APK тестовый, физический телефон здесь не проверен.
5. Во вкладке **«Сайт / браузер»** выбери **Temka-Studio-Android.zip** → «Обновить сайт». APK уже лежит внутри ZIP в downloads/. **Старый Publisher1.0.9 пропускал APK — нужен1.1.0.** Репозиторий сайта прежний, ttt170689-afk/temka_play_site. Publisher завершает работу после отправки в GitHub, не ждёт и не проверяет Vercel. Production-сайт из этого чата не опубликован.

## Что осталось в лаунчере

«⋯ → Свойства» содержит только «Об игре» и «Бета-тест»: ввод кода и статус. Управление, генератор, списки заявок/ключей и admin HTTP-методы удалены **даже для тебя**. Раньше вкладка была доступна только подтверждённым сервером создателям, не обычным игрокам. До установки новой версии старый клиент ещё может её показывать.

## Доступ и данные

Ник temka_play_official или вход в GitHub не заменяет серверную роль. Beta Test проверяет твою подтверждённую Auth-учётку и creator_admin; все действия дополнительно защищены сервером. Токены/новые ключи только в памяти, не сохраняются в журнал/файлы. Публичный ключ проекта внутри программы не даёт административных прав.

**Новый SQL не нужен для переноса управления.** Существующие beta-access, ключи, заявки, SMTP, права и аккаунты сохраняются. Если ещё не применял отдельный прошлый SQL1.9.0 для чата/профилей, это по-прежнему нужно для этих функций, но не нужно повторно создавать сервер ради Publisher.

Ключ виден полностью один раз. Если ответ потерялся, создание могло пройти; проверь список и при необходимости отключи неполученный ключ. Нет слепого автоповтора. Отключение ключа запрещает новые заявки; существующий допуск отзывается отдельно у игрока.

ЛС, друзья, профили, библиотека и Soon сохранены. Выдача бета-допуска не устанавливает игру. На сайте нет админ-панели, аккаунтов или новых AI-картинок.

Мобильный исходный ZIP — Android Studio/Xcode, не импортировать в Publisher. Готового IPA нет. Publisher installer — небольшая отдельная программа, большой Windows EXE лаунчера локально не собирался.
