## 1.7.3 — системное копирование

- Исправлены кнопки копирования @юзернейма в профиле и разделе друзей. Браузерный Clipboard API блокировался политикой Electron; теперь установленный клиент использует ограниченный IPC и системный буфер.
- Общая реализация также используется кнопкой копирования бета-кода.
- Асинхронная запись и read-back Electron44 обязательно ожидаются; только совпадение полного текста даёт успех. Отказы, неверные ответы IPC, NUL/пустые/слишком большие входные данные не создают ложного успеха.
- Renderer не получает чтение буфера. Чужие окна/фреймы не авторизованы; browser permissions остаются deny.
- Native smoke проверяет действительные OS clipboard contents после нажатия обеих кнопок, Unicode, отказ ОС и недоверенное окно. Онлайн-профиль в smoke синтетический; внешние сервисы не вызываются.
- 21 protected file / protocol3; исправления CRLF из1.7.2 сохранены. Пользователь подтвердил рабочую1.7.2; она была базой этой версии.

## 1.7.2 — CRLF/LF в регрессии импорта Publisher

- Исправлено ложное несовпадение восстановленного native smoke и защищённой копии при Windows checkout (CRLF → LF).
- Сравнение сохраняет полное содержимое; нормализуются только переводы строк, не удаляются пробелы или другие символы. SHA-256 runtime и отказ при порче bundle не ослаблены.
- Три варианта restoration fixture (LF, CRLF, mixed), идемпотентность восстановления и дочерние проверки самого теста из CRLF/mixed checkout.
- Проверено воспроизведение падения предыдущего теста на CRLF. Новый архив проверяется после реального кода импорта Publisher и Git checkout с core.autocrlf=true, а не только исходные файлы Linux.
- Windows runner и публикация не запускались из чата. Функциональность, данные пользователей и мобильный выпуск не менялись.
