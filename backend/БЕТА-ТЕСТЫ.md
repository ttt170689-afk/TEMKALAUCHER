# Закрытая бета и Discord Temka Studio

## Как выдавать приглашения сейчас

Твой подтверждённый онлайн-аккаунт уже имеет creator_admin. Повторно назначать роль, настраивать SMTP или создавать базу не нужно.

В лаунчере: **Библиотека → ⋯ у игры → Свойства → Управление**. Панель открывается после серверной проверки роли, не по локальному имени.

Для первой беты на шесть человек рекомендую **6 отдельных кодов по1 месту**, режим **«Моё одобрение каждой заявки»**, срок ввода **72 часа**. Это пример настройки, а не обещание, что коды уже созданы.

1. Создай код. Открытый код показывается только при создании — сразу скопируй его. Если потерял, создай новый, старый отключи.
2. Передай его конкретному человеку лично. Не публикуй код в общем канале Discord.
3. Игрок входит через подтверждённую почту, выбирает онлайн-юзернейм, открывает ту же игру → Свойства → Бета-тест → вводит код.
4. При ручном режиме статус «Ожидает решения». В «Управлении → Обновить» проверь @юзернейм/UUID, нажми «Одобрить» или «Отклонить».
5. Игрок нажимает «Проверить статус». Автоматические push-уведомления о решении пока не подключены.

Можно создать один код на6 заявок или выбрать «Доступ сразу после проверки», но пересланный код тогда легче попадёт не тому человеку. Никакого общего мастер-кода в лаунчере нет.

### Важные различия

- Срок кода ограничивает **ввод**, не длительность уже одобренного участия.
- Место тратится на заявку, в том числе ожидающую; отказ не возвращает место в этот код.
- «Отключить код» останавливает новые заявки, но не выгоняет уже допущенных. Для этого нужен **«Отозвать доступ» у конкретного игрока**.
- Отозванный/отклонённый игрок не обходит твоё решение другим автоматическим кодом: доступ восстанавливаешь ты.
- Доступ связан с подтверждённым аккаунтом и игрой, а не с ником на устройстве или Discord-ролью.

## Что ещё нужно для запуска именно закрытой игры

Нынешняя система — **реестр допуска**, а не скачивание/запуск готовой беты. В библиотеке пока стоит «Скоро». Публичная браузерная версия и закрытая бета — разные способы доступа. Ни получение approved, ни Discord-роль сами по себе не закрывают публичный URL.

Когда бета-сборка будет готова:
1. Выделить закрытую версию игры отдельно от открытой.
2. На доверенном backend проверить подтверждённый аккаунт и approved-допуск к конкретной игре.
3. Выдать короткоживущий сеанс/одноразовый билет запуска, не постоянную публичную ссылку. Сервер игры должен сам проверять доступ; проверка только JavaScript-кнопки обходится.
4. При отзыве прекращать/обновлять допуск на стороне игры. Локальные уже скачанные файлы невозможно гарантированно «забрать назад».
5. Тот же игровой backend сможет передавать реальные часы, уровни и достижения. Сейчас такого подключения нет — нужны исходники/сервер самой игры.

Ни постоянные секреты, ни service_role нельзя встраивать в игру или лаунчер. Домашний Xeon для друзей/выдачи разрешений сейчас не требуется; игровое размещение и ограничения бесплатных тарифов — отдельная задача.

## Создать Discord: короткий план

**Сервер пока не создан из чата.** Прямого управления Discord здесь нет. Обычный сервер и описанные каналы бесплатны; Nitro, VPS и платный бот не нужны.

В Discord: **«+» в списке серверов → Создать свой → название “Temka Studio”**. Значок можно взять из `assets/icon.png` проекта. Владельцем должен остаться твой Discord-аккаунт. Включи двухфакторную защиту, не передавай пароль, резервные коды и токены.

### Роли (сверху вниз)

| Роль | Что разрешать |
|---|---|
| Автор | Ты — владелец сервера. Роль можно использовать для оформления; другим её не выдавать. |
| Модератор | Управление сообщениями/ветками, тайм-аут участников. Administrator, управление сервером/ролями и вебхуками без необходимости не давать. |
| Бета-тестер | Просмотр закрытой категории беты, сообщения и подключение к её голосовому каналу. |
| Игрок | Обычное общение в открытых каналах. Для маленького сервера можно обойтись @everyone. |

### Каналы

**НАЧНИ ЗДЕСЬ**
- `#правила` — читать всем, писать только автору/модератору.
- `#объявления` — обновления лаунчера и игр; только автор/модератор публикует.
- `#как-начать` — ссылки на официальный лаунчер, правила ника и где сообщать ошибки. Никаких секретных бета-кодов.

**СООБЩЕСТВО**
- `#общение`
- `#поиск-друзей` — люди делятся @юзернеймом, не почтой.
- `#помощь-лаунчер` — версия клиента, описание ошибки, очищенный скриншот.
- `Общая комната` — голосовой.

**ЗАКРЫТАЯ БЕТА**
- `#бета-новости` — читать тестерам, писать автору.
- `#бета-чат`
- `#баги-и-отзывы` — сначала обычный текстовый канал. Форум можно добавить позже после настройки сообщества.
- `Тестовая сессия` — голосовой.

### Главное: права закрытой категории

На категории «ЗАКРЫТАЯ БЕТА»:
- @everyone → **Просмотр каналов: запретить**.
- Бета-тестер и Модератор → **Просмотр каналов: разрешить**.
- Синхронизировать права дочерних каналов с категорией. Для `#бета-новости` отдельно запретить тестерам «Отправлять сообщения».
- Не выдавать обычным участникам Administrator: он обходит запреты категории.
- Проверить доступ через просмотр сервера от лица роли либо с братом/вторым обычным аккаунтом. Не считать скрытым канал, который ты сам как владелец всё ещё видишь.

### Как связать с приглашениями

Пока **вручную**: одобрил игрока в лаунчере → убедился, какой Discord принадлежит этому человеку → выдал роль «Бета-тестер». Роль Discord не выдаёт допуск в базе. При исключении отдельно отозвать допуск в лаунчере и снять Discord-роль. Автоматический бот/связка аккаунтов не реализованы.

Для входа на сервер создай приглашение через интерфейс Discord; для первой группы можно поставить срок и лимит использований. После создания пришли **только приглашение** вида discord.gg/… — тогда можно добавить настоящую кнопку в лаунчер/на сайт. Сейчас выдуманной ссылки или неработающей кнопки нет.

### Шаблон сообщения о баге

- Игра/лаунчер и версия:
- Устройство/ОС:
- Что нажал (по шагам):
- Что ожидал:
- Что получилось:
- Повторяется ли:
- Скриншот/лог без кодов, токенов, почты и персональных файлов.

Правила коротко: уважение, без спама/рекламы/травли; приватные данные не публиковать; материалы закрытой беты не пересылать без разрешения автора. В правилах не обещать, что запрет пересылки технически невозможно обойти.
