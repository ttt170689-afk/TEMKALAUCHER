# TemkaLauncher 1.9.4 · Alpha · ПК

Общее обновление с Android 0.4.3: личные текстовые сообщения друзьям, статус текущей игры и история отслеживаемых запусков. Настройки существующего онлайн-сервера сохранены.

## Использование

1. На первом экране: «Войти в аккаунт» → прежняя подтверждённая почта → код из письма. Лаунчер сам открывает общий аккаунт. Новый пользователь выбирает «Создать аккаунт», подтверждает почту и выбирает свободный @юзернейм.
2. Добавить друга и принять заявку. Друзья → «Написать» или конверт «Сообщения» в шапке. До 2000 символов; Enter — перенос, Ctrl+Enter — отправка.
3. Непрочитанные и переписка общие на ПК и Android при входе в тот же онлайн-аккаунт. История сохраняется на сервере. После удаления друга старая переписка доступна, новые сообщения запрещены.
4. В личном профиле и карточках игроков есть «Активность в лаунчере» и последние 20 запусков. В списке друзей показывается текущая игра.

**Fantazia RP и TemkaWorld остаются «Скоро».** Сейчас нет доступного запуска игры из библиотеки, поэтому в обычной установке игровая история будет пустой. Открытие внешней ссылки, браузерной вкладки, самого лаунчера или бета-панели не считается игрой. Перед реальным использованием активности нужно подключить готовую игру к отслеживаемому нативному запуску; механика и ограничения описаны в backend/ЧАТ-И-АКТИВНОСТЬ.md. Часы/уровни/достижения поступают только из доверенного игрового backend, эта история их не изменяет.

## Сервер: одно аддитивное обновление

В комплекте backend/online-1.9.0.sql: обновление друзей, профилей и новые таблицы/RPC чата/активности. Выполнить один раз в SQL Editor существующего проекта владельца; последний результат — TEMKA_CHAT_ACTIVITY_READY. Повторный запуск безопасен. Требуется ранее установленная базовая схема с beta-access. Аккаунты, creator_admin, фото, друзья, beta-коды не сбрасываются. Gmail SMTP и подтверждение почты не перенастраивать. В интерфейсе лаунчера нет tutorial/SQL-кнопок.

Production SQL и публикация из этого чата не выполнялись. Передаваемый ZIP — исходники, не установленное обновление сервера.

## ПК через Publisher

Импортировать именно **TemkaLauncher-1.9.3-sources.zip** в имеющийся TemkaPublisher 1.1.0, вкладка лаунчера, версия 1.9.3. Репозиторий: https://github.com/ttt170689-afk/TEMKALAUCHER. Не перезаписывать существующие теги: если номер занят, выбрать новый больший номер. Номер берётся из package.json.

Publisher заменяет desktop-шаблон. Vite перед сборкой проверяет SHA-256 и восстанавливает **32 защищённых файла / protocol 3** из native-bundle, затем повторяет TypeScript и runtime-тесты. Защищены updater, OS clipboard, tracked-game, контракты и обязательный Electron smoke. Не удалять native-bundle/build-tools и не обходить CI. Переводы строк Windows CRLF нормализуются перед проверкой.

Node 22.12+: `npm ci`, `npm test`, `npm run build`, `npm run test:smoke` (Linux: `xvfb-run -a npm run test:smoke`). Windows/Linux пакеты собираются штатным CI. Большой Windows-установщик локально не создавался и не скачивался. Мобильный ZIP в Publisher не импортировать.

## Ограничения

Текстовые ЛС — не сквозное шифрование: администраторы проекта имеют доступ к базе. Нет звонков, файлов, магазинов и push при закрытом приложении. Список диалогов опрашивается каждые 8 секунд, открытая переписка — каждые 3,5 секунды; в скрытом интерфейсе опрос чата приостанавливается. Сервер: до 20 новых сообщений в минуту на отправителя. Лимит выдачи — 100 диалогов, сообщения постранично по 50.

Сохранены библиотека, свойства через ⋯, beta-права, единый выбор фото, поиск от двух символов, имя + @юзернейм, до 25 символов, Alpha, готовность Fantazia 80% / TemkaWorld 10%, вишлист без почты и настоящее обновление GitHub Releases. SMTP и права автора не менялись. Никакого нового XP.
