# Магазин — неопубликованный черновик

Вкладка добавлена в исходники. Это витрина, не готовая платёжная система. Текущая версия пакета сохранена: новый релиз не опубликован и старые теги не перезаписаны.

Наборы взяты из server.js репозитория https://github.com/ttt170689-afk/fantazia-shop: 60/59₽,150/139₽,320/269₽,700/549₽,1500/999₽,3500/1999₽. Клиент не меняет баланс и не вызывает API магазина. Все покупки отключены. Музыка не выбрана; подготовлены play/pause, volume, остановка при уходе, без autoplay.

Нужно получить публичную страницу DonationAlerts, выбранный трек с правом использования и подтвердить наборы. Автоматическую выдачу реализовать только сервером: verified Supabase UID, доверенный каталог цен, заказ до оплаты, проверка DonationAlerts OAuth/API (не произвольный неподтверждённый webhook), валюта и сумма, уникальный ID платежа/защита повторов, атомарное начисление, постоянная БД. Секреты только на сервере. Нельзя использовать текущие незащищённые API :nick/spend, claim и admin/give. У магазина нет проверки владельца аккаунта, цена приходит от клиента, DA_SECRET допускает отсутствие проверки, default ADMIN_PASS известен из публичных исходников.

Работающий friends/DM/Supabase сервер не изменён. Нет новых EXE/APK, размещения магазина или оплаты. Черновик нужно завершить и версионировать перед публикацией через Publisher.
