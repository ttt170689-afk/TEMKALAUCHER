# Изменения

## 1.5.8 — подготовлено 2026-10-12

- Убрано обращение к GitHub REST API при проверке обновлений.
- Прямое чтение latest/download/latest.yml или latest-linux.yml, сверка с манифестом конкретного тега.
- HEAD-проверка доступности установщика без загрузки его содержимого.
- Сохранены сверка SHA-512/размера с updater, защита от отката и обработка ошибок.
- Требуется native-шаблон Publisher 1.0.7.


## 1.5.6 — подготовлено 2026-10-12

- Проверка GitHub API и манифеста; закреплённый feed конкретного тега.
- Сверка версии, файла, размера и SHA-512 с движком обновления.
- Панель версий/ошибок/времени проверки, удалён фиктивный таймер уведомлений.
- Защита сборки от потери нового native-кода через старый Publisher.


## 1.5.5 · Альфа — подготовлено 2026-10-11

- Отключены начисления XP, уровни и награды интерфейса; исторические данные сохранены.
- Однокликовый локальный вишлист без email; миграция старых записей без адресов.
- Системный выбор папки Electron, проверка записи, корректная отмена и блокировка дубликатов.
- Нативный шаблон поддерживается Publisher 1.0.5.
- Дополнена инструкция друзей: Free Cloud, домашний Xeon и ограничения текущего клиента.

## 1.5.3

## 1.5.2 — 2026-10-11

- Доступные имена кнопок навигации сохраняются в компактном меню.
- Smoke-тест проверяет узкую и широкую раскладку, отдельно подтверждает регистрацию.
- Диагностика неудачных smoke-тестов сохраняется в GitHub Actions Artifacts.
- Publisher 1.0.2 обновляет шаблон сборки и миграцию старого Sidebar.


## 1.5.1 — 2026-10-11

- Лимит ника увеличен с 16 до 25 во всех полях и валидации.
- Счётчик длины при регистрации и в профиле.
- Smoke-тест проверяет ввод 25 символов, отсечение 26-го и сохранение длинного ника.
- Добавлена отдельная программа Temka Publisher: ZIP → исходники в GitHub → сборка EXE → релиз.


## 1.5.0 — 2026-10-11

- Переход с ZIP-замены интерфейса на обновление всего приложения через NSIS + electron-updater.
- Источник: публичные GitHub Releases `ttt170689-afk/TEMKALAUCHER`.
- Единая версия из package.json; фиксированные зависимости и lock-файл.
- Установочный EXE Windows x64 и автоматическая сборка/публикация через GitHub Actions.
- Разделение загрузки и установки: фоновая загрузка, установка при полном выходе или по кнопке перезапуска.
- Обработка ошибки проверки вместо ложного сообщения об отсутствии обновлений.
- Защита от одновременных скачиваний, запрет понижения версии, проверка целостности средствами electron-updater.
- Исправление команды обновления из трея и закрытия окна при недоступном трее.
- Изолированный preload, проверка источника IPC, блокировка навигации окна на внешние страницы.
- 11 unit-тестов и smoke-тест Electron.

Исходный дизайн и локальные профили сохранены. Установка и запуск игр не входят в эту версию.
